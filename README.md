# Sistema de Análisis del SEN (Sistema Eléctrico Nacional de Cuba)

Esta aplicación proporciona un análisis interactivo del Sistema Eléctrico Nacional de Cuba, basado en datos extraídos de CubaDebate.

## Características

🔍 **Análisis Interactivo**: Visualización de déficit, disponibilidad y comparativas
📊 **Gráficos Dinámicos**: Evolución temporal de los indicadores eléctricos
📈 **Estadísticas Detalladas**: Métricas y análisis por plantas
🌞 **Energía Solar**: Seguimiento de parques fotovoltaicos
📋 **Datos Detallados**: Tablas interactivas con filtros y descargas

## Funcionalidades

- **Inicio**: Resumen del último día disponible
- **Déficit**: Análisis histórico del déficit energético
- **Disponibilidad**: Análisis de disponibilidad del sistema
- **Comparativas**: Análisis adversarial déficit vs disponibilidad

## Tecnologías

- Streamlit para la interfaz web
- Plotly para visualizaciones interactivas  
- Pandas para procesamiento de datos
- Python 3.9+

Desarrollado para monitorear y analizar el estado del sistema eléctrico cubano.
